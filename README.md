# 365 Days of AI/ML

A one-year mission to become an AI/ML engineer, with a deep focus on agentic AI, and to land a job by Day 365. I'm learning in public and committing my work here every day.

**Started from:** Python basics, from zero
**Goal:** an AI/ML engineer job through off-campus hiring
**Study time:** 4 hrs on weekdays, 8 hrs on weekends

## Roadmap

| Days | Phase | Focus |
|---|---|---|
| 1-30 | Python and DSA foundations | Python (CS50P), testing, Git, data structures, a packaged capstone project |
| 31-60 | Core CS and data basics | SQL, Linux and the shell, more DSA, linear algebra |
| 61-100 | Data stack and math | NumPy, pandas, matplotlib, probability and statistics |
| 101-150 | Classical ML | scikit-learn, model evaluation, Kaggle, first ML project |
| 151-200 | Deep learning | PyTorch, neural networks, NLP, transformers |
| 201-250 | LLMs and RAG | LLM APIs, embeddings, vector databases, retrieval-augmented generation |
| 251-310 | Agentic AI | Tool calling, agent loops, multi-agent systems, evals, deployment |
| 311-340 | Interview mode | DSA revision, ML fundamentals, system design, resume and portfolio |
| 341-365 | Job hunt sprint | Applications, referrals, mock interviews |

## How I work

- I write all code myself. I use AI tools only to explain an error after I've tried to fix it.
- Every day ends with notes, a commit, and a push.
- Every module ends with tests, and `ruff` and `pytest` run clean before I commit.
- I do a weekly review every 7 days and a monthly scorecard every 30 days.
